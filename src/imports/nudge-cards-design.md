## Figma AI Prompt - **3 Swipeable Nudge Cards**

```
Create **3 swipeable cards** explaining each nudge feature. Horizontal swipe navigation (like Tinder/Instagram Stories). Dark UI matching your toggle design. Each card = **one nudge, one scenario, one animation**.

**CARD 1: Haptic Pulse**
```
HEADER: "Subtle Haptic Pulse" + ✨ icon
SCENARIO: "Evening study -  12min → 2min left"
ANIMATION: Phone bottom ripples teal waves
  [Single pulse] → [Double pulse] → [Triple pulse]
TEXT: "Pulses strengthen as time runs out"
FOOTER: Swipe indicator "1/3" + Next arrow
```
**Teal accent color (#14B8A6)**

**CARD 2: Audio Tempo Tone**  
```
HEADER: "Audio Tempo Tone" + 🎵 icon
SCENARIO: "Morning routine -  Brushing → 1min left"  
ANIMATION: Purple waveform pulses from speaker
  [Slow chimes] → [Medium tempo] → [Fast chimes]
TEXT: "Chimes speed up to match your drift"
FOOTER: Swipe indicator "2/3" + Next/Back arrows  
```
**Purple accent color (#8B5CF6)**

**CARD 3: Ambient Light Cue**
```
HEADER: "Ambient Light Cue" + 💡 icon  
SCENARIO: "Work call -  5min → 30sec left"
ANIMATION: Pink glow moves around screen edges
  [Top-left glow] → [All corners] → [Full tint]
TEXT: "Screen glows guide your attention naturally"
FOOTER: "3/3" + "Got it!" button (teal)
```
**Pink accent color (#EC4899)**

**CARD DESIGN SYSTEM**:
```
**Size**: Full screen (iPhone 14 Pro frame)
**Background**: Each card = gradient matching accent color (10% opacity)
**Layout**: Header(20%) + Scenario(15%) + Animation(50%) + Text(10%) + Footer(5%)
**Glassmorphism**: Scenario card + footer (8px blur)
**Spacing**: 72px margins, 8pt grid
**Typography**: Inter Bold headers, clean body text

**SWIPE NAVIGATION**:
```
- Dots at bottom: ●○○ | ○●○ | ○○●
- Subtle peek of next/previous card (20% width)
- Swipe left/right gestures
- Card 3 has "Got it!" button (returns to dashboard)
```

**ANIMATIONS** (4-second loops):
```
Haptic: Teal ripples from bottom edge
Audio: Purple waveform from speaker grille  
Light: Pink glow traveling screen perimeter
```

**Not Cluttered**:
```
- 1 animation per card = 1 focal point
- Max 8 words per scenario  
- Max 6 words explanation text
- Massive negative space
- Perfect visual breathing room
```

**Style**: Duolingo onboarding cards, Tinder feature explainers, Instagram onboarding swipes.

**Result**: Swipe → instant understanding of each nudge. Perfect for quick onboarding.
```

---

**Flow**: User taps toggles → "3 Swipe Cards" → Understands all nudges → "Got it!" → Back to dashboard

**Perfect for presentation**: Judges swipe through 3 elegant cards showing **feature mastery + UX polish**.
