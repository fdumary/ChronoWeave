Weekly Drift Calendar Animation

The calendar grid represents days of the week (Mon–Sun) and time periods (Morning, Midday, Afternoon, Evening).

When the screen loads:

• Drift indicators appear sequentially across the week
• Animation starts at Monday and moves toward Sunday
• Each indicator uses a soft scale-in effect

Scale animation:

0.8 → 1.0

Animation delay between cells: ~80–120ms.

Drift Indicator Interaction

When a user taps a drift indicator:

• The block expands slightly
• A small tooltip appears above it

Example tooltip content:

Wednesday Evening
Strong time drift detected
Estimated accuracy: 58%

The tooltip fades out when tapping elsewhere.

Pattern Insight Card Animation

Below the calendar, display the insight card summarizing patterns.

When the calendar animation finishes:

• The card slides up from below
• It fades in simultaneously

Animation duration: ~0.4 seconds.

Example insight text:

“Your time tends to move faster during evening hours.”

Smart Schedule Suggestion Animation

Display the recommended focus windows for the next day.

When this section appears:

• Schedule blocks slide upward one after another
• Each block appears with a slight scale animation

Example sequence:

Focus Window 1 appears
Focus Window 2 appears
Focus Window 3 appears

Delay between blocks: ~120ms.

Weekly Accuracy Line Chart Animation

When the chart enters the screen:

• The line draws from left to right
• Data points appear sequentially along the line
• Each point scales in slightly when it appears

Animation timing:

Line drawing duration: ~1 second.

Chart Interaction

When the user taps a data point:

• The point enlarges slightly
• A small value label appears above it

Example:

78% accuracy

The label disappears when the user taps elsewhere.

Reflection Prompt Interaction

When a user selects an option in the reflection prompt:

• The selected option briefly scales up
• A subtle check indicator appears

Bottom Button Animation

The main button (“Run a New Calibration Test”) should include:

• A small press animation when tapped
• Scale: 1 → 0.96 → 1

Motion Principles

Animations should feel:

• smooth
• subtle
• calm

Avoid fast or distracting movement.

Animations should reinforce the concept of time flow and behavioral patterns, helping users understand their time rhythm naturally.
