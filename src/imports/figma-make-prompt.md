# Prompt for Figma Make — ChronoWeave Auth + Updated Flow

Update the **ChronoWeave mobile app UI prototype** by adding **authentication screens (Sign Up and Log In)** before users access the dashboard.

Maintain the **existing visual design system**:

• Flat design
• **No gradients**
• Soft pastel color palette
• Rounded cards and buttons
• Calm mental-wellness style
• Friendly **star-shaped mascot** used across screens

Use the following colors:

Lavender — #CFC6FF
Mint — #CFF4E8
Soft Blue — #CFE7FF
Pale Yellow — #FFF3C6
Coral — #FFB4A2
Soft Purple — #C7B8FF

Backgrounds should remain **light and calming**.

Typography should use a **clean rounded sans-serif font**.

---

# Updated User Flow

Design the following screens in this order.

---

# Screen 1 — Landing / Welcome

Purpose: Introduce the app and provide authentication entry.

Elements:

App name
**ChronoWeave**

Tagline
“Learn how time feels to you.”

Centered **star mascot illustration**.

Primary buttons:

**Sign Up**

Secondary button:

**Log In**

Optional small link at bottom:

Continue as Guest

The screen should feel welcoming and calm.

---

# Screen 2 — Sign Up

Title:

**Create your account**

Use a centered rounded card with fields:

Name
Email
Password

Primary button:

**Create Account**

Secondary text link:

Already have an account? **Log In**

Optional button:

Continue with Google

Mascot can appear beside the form.

---

# Screen 3 — Log In

Title:

**Welcome back**

Fields:

Email
Password

Primary button:

**Log In**

Links:

Forgot Password
Don’t have an account? **Sign Up**

Keep the layout minimal with clear spacing.

---

# Screen 4 — Time Feeling Selection (First-Time Setup)

Purpose: Understand the user’s perception of time.

Title:

“How does time usually feel to you?”

Display **three rounded option cards** with icons and mascot expressions.

⚡ Time flies
🌫 I lose track of time
🐢 Time drags

Selected card slightly enlarges.

Bottom button:

**Continue**

Returning users skip this step.

---

# Screen 5 — Calibration Test 1

Title:

Quick Time Test

Instruction:

“Hold the button when you think **10 seconds** have passed.”

Center element:

Large circular **Hold Button**.

Add subtle **pulse rings** to represent time passing.

After completion show a **result card** displaying:

Estimated time
Actual time

Mascot reaction based on accuracy.

---

# Screen 6 — Calibration Test 2

Instruction:

“Tap when you think **30 seconds** have passed.”

Large tap button in center.

After interaction show **friendly result card**.

---

# Screen 7 — Drift Map

Title:

**Your Time Drift Map**

Show **three stacked cards**:

Morning — Stable (blue)
Afternoon — Moderate Drift (purple)
Evening — Fast Drift (orange)

Each card includes:

• small mascot
• color-coded state
• short explanation

---

# Screen 8 — Dashboard

Title:

**Today’s Time Rhythm**

Display a **timeline-style card layout** showing time stability blocks.

Example:

Morning — Stable
Midday — Slight Drift
Evening — Fast Drift

Include a toggle:

**Enable Rhythm Cues**

Mascot appears in the header.

Add simple **bottom navigation bar**:

Dashboard
Insights
Profile

---

# Screen 9 — Live Nudge

Notification-style screen.

Mascot with subtle pulse around it.

Message:

“Time may be moving quickly right now.”

Options:

Start rhythm cue
Remind me later
Dismiss

---

# Screen 10 — Weekly Insight

Title:

**Your Weekly Insight**

Display insight cards such as:

“Your time runs fastest during evening screen use.”

“Your time estimation improved this week.”

Include button:

**Run a new calibration test**

Mascot appears celebrating improvement.

---

# UX Principles

Design should feel:

• Supportive
• Curious
• Calm
• Non-judgmental

Avoid negative messaging.

The app should feel like a **friendly companion helping users understand how time feels to them.**
